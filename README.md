# 💼 JNova - Job Connect

### A Job Connection Platform

JNova is a job connection platform designed to help job seekers discover opportunities and connect with recruiters.

🚧 **Project Status:** Currently under development.

## 🌐 Live Demo

[Live Demo](https://j-nova-job-connect.vercel.app/)

## ✨ Features

- 🔍 Job search and job listings
- 👤 User registration and login
- 🔐 Forgot password functionality
- 🏢 Recruiter and job seeker profiles
- 📄 Job application functionality
- 🔎 Search and filtering
- 📱 Responsive user interface

## 🛠️ Tech Stack

- ⚛️ React.js
- ⚡ Vite
- 🎨 Tailwind CSS
- 🟨 JavaScript
- 🧭 React Router DOM
- 🎯 React Icons
- 🔧 Git & GitHub
- ▲ Vercel

## 📌 Project Goals

JNova aims to provide a simple and user-friendly platform where job seekers can explore job opportunities and recruiters can connect with suitable candidates.

## 🚀 Future Updates

More features and improvements will be added as the project development continues.
